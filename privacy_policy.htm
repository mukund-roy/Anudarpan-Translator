Privacy Policy

Anudarpan Translation and IME tool

Effective Date: 6 October 2026

Anudarpan Translation and IME tool is a Chrome extension developed to provide Indian-language translation, Indic-language typing, and speech input on webpages.

This Privacy Policy explains what information the extension processes, how it is used, and when information is transmitted to external services.

1. Information We Process

The extension may process the following information when the user explicitly uses its features:

Text selected for translation

When the user selects text and chooses Translate to, the selected text is sent to the translation service selected by the user:

  • CDAC translation service; or
  • Google Translate service.

The selected text is used solely to obtain the requested translation.

Speech input

When the user activates the speech-input/microphone functionality, audio captured from the user's microphone is sent to the CDAC speech-recognition service for transcription.

The audio is used to provide the requested speech-to-text functionality.

User settings

The extension stores certain preferences locally using Chrome's storage mechanism, including:

  • Selected translation provider
  • CDAC API settings
  • Google Translate API settings
  • Target language preferences
  • Translation insertion preferences
  • Indic typing preferences
  • Other extension configuration settings

These settings are stored using chrome.storage.local.

2. Information We Do Not Collect

The extension does not intentionally collect or maintain:

  • Browsing history
  • Passwords
  • Authentication credentials from websites
  • Credit/debit card information
  • Website login information
  • Personally identifiable information unrelated to the requested translation or speech functionality
  • Advertising profiles
  • User tracking information
  • Analytics or behavioral profiles

The extension does not contain advertising or user-tracking functionality.

3. How Information Is Used

Information processed by the extension is used only to provide its functionality, including:

  • Translating user-selected text
  • Inserting translations into supported editable fields
  • Providing Indic-language typing
  • Converting user speech into text
  • Saving extension preferences

The extension does not sell user information or use translated text or speech recordings for advertising purposes.

4. Third-Party Services

To provide translation and speech functionality, the extension communicates with external services.

CDAC

When CDAC services are selected, user-requested translation text may be transmitted to the CDAC translation service.

Speech input may be transmitted to the CDAC speech-recognition service when the user activates speech input.

Google Translate

When Google Translate is selected, the text submitted by the user for translation is transmitted to Google Translate to obtain the requested translation.

Google's handling of data is subject to Google's applicable privacy policies and terms.

The extension does not control how third-party services process information after it has been transmitted to them.

5. User Control

The user controls when translation and speech functionality is invoked.

The extension does not automatically send arbitrary webpage content for translation. Text is transmitted when the user requests translation.

Similarly, microphone/audio data is transmitted only when the user activates the speech-input functionality and grants the required browser microphone permission.

6. Local Storage

Extension preferences are stored locally using Chrome's chrome.storage.local API.

The extension does not use local storage to maintain a history of translated webpage content.

7. Data Security

The extension uses HTTPS connections when communicating with supported external services.

Users should avoid submitting confidential, classified, financial, medical, authentication, or other sensitive information to third-party translation or speech services unless they are authorized to do so and the applicable service's privacy and security requirements permit it.

8. Data Retention

The extension itself does not maintain a server-side database of translated text or speech recordings.

Data transmitted to third-party services may be subject to those services' own retention and processing policies. Users should refer to the applicable third-party service privacy policies for details.

9. Children's Privacy

The extension is not specifically directed toward children and does not knowingly collect personal information from children.

10. Changes to This Privacy Policy

This Privacy Policy may be updated when the extension's functionality, data practices, or applicable requirements change. The updated version will be made available at the same privacy-policy URL.
